Guides for running and extending **Better Auth Server** — your own Better Auth–based OpenID / OAuth **identity server** on Next.js + PostgreSQL.

This kit is a fork of [daveyplate/better-auth-nextjs-starter](https://github.com/daveyplate/better-auth-nextjs-starter). Maintained at [t3xy.dev](https://t3xy.dev). See [Credits](https://github.com/t3xydev/better-auth-server/blob/main/README.md#credits) in the README.

**Live demo:** [https://betterauth-starterkit.t3xy.dev/](https://betterauth-starterkit.t3xy.dev/)

## Useful paths

| Path | Purpose |
|---|---|
| `/auth/sign-in` | Sign-in UI |
| `/account/*` | Account settings (Better Auth UI) |
| `/account/billing` | Account subscription (when billing is enabled) |
| `/pricing` | Public plan catalog (when billing is enabled) |
| `/admin/clients` | OAuth client admin (admin role required) |
| `/admin/users` | List users; set privilege and catalog roles/groups |
| `/admin/roles` | Catalog roles for segmentation |
| `/admin/groups` | User groups for segmentation |
| `/admin/invites` | Create and manage user invites (admin role required) |
| `/invite/activate/[token]` | Invite welcome page; accept or reject |
| `/api/auth/*` | Better Auth API |
| `/api/health` | Liveness (2xx); add `?ready=1` for DB readiness |
| `/.well-known/openid-configuration` | OIDC discovery |
| `/api/auth/reference` | OpenAPI reference (openAPI plugin) |
