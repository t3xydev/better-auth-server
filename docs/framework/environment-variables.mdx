## Required

These variables must be set for the application to start.

| Variable | Description |
|----------|-------------|
| `BETTER_AUTH_URL` | Public base URL of the auth server (e.g. `https://auth.example.com`). Used as the JWT issuer, OAuth audience, and resource identifier. Defaults to `http://localhost:3000` in development. |
| `BETTER_AUTH_SECRET` | Random secret used by Better Auth to sign sessions and tokens. Generate one with `openssl rand -hex 32`. |
| `DATABASE_URL` | PostgreSQL connection string (e.g. `postgresql://user:pass@host:5432/dbname`). Used by Drizzle ORM and Better Auth. |

## Better Auth

| Variable | Description |
|----------|-------------|
| `BETTER_AUTH_API_KEY` | API key for the Better Auth Dash plugin and Infra email. Required for `/api/auth/admin`. Also used to send mail when SMTP is not configured (Pro+). |
| `BETTER_AUTH_TRUSTED_ORIGINS` | Comma-separated list of additional trusted origins for CSRF and redirect validation (e.g. `https://app.example.com,https://admin.example.com`). `BETTER_AUTH_URL` is always included. Wildcards like `https://*.example.com` are supported. |

## OAuth Provider

These configure the OAuth 2.1 / OpenID Connect provider plugin.

| Variable | Description | Default |
|----------|-------------|---------|
| `OAUTH_ISSUER` | Override the JWT `iss` claim. Falls back to `BETTER_AUTH_URL`. | `BETTER_AUTH_URL` |
| `OAUTH_AUDIENCE` | Protected resource identifier and JWT `aud` for access tokens. Also used as the default (and only allowed) resource for Dynamic Client Registration. Falls back to `BETTER_AUTH_URL`. | `BETTER_AUTH_URL` |
| `ALLOW_DYNAMIC_CLIENT_REGISTRATION` | Enable OAuth dynamic client registration (`/oauth2/register`) for authenticated users. Set to `"true"` to enable. | `false` |
| `ALLOW_UNAUTHENTICATED_CLIENT_REGISTRATION` | Allow public clients to register without a session (useful for MCP). Requires DCR to be enabled. Set to `"true"` to enable. | `false` |

## Email

Delivery preference (first match wins):

1. **Resend HTTPS** — when `SMTP_*` is set and the host is `smtp.resend.com` (or `SMTP_PASS` starts with `re_`). Sends via `https://api.resend.com` — preferred because SMTP ports 587/465 often hit `ETIMEDOUT` locally and on Railway.  
2. **SMTP** — other providers when all `SMTP_*` variables below are set (nodemailer; use `465` for implicit TLS or `587` for STARTTLS)  
3. **Better Auth Infra** — when `BETTER_AUTH_API_KEY` is set (Pro+ transactional email)  
4. **Console** — logs the message (local/dev fallback)

| Variable | Description | Default |
|----------|-------------|---------|
| `SMTP_HOST` | SMTP server hostname (e.g. `smtp.resend.com`, `smtp.gmail.com`). Resend is detected and routed over HTTPS. | None (disabled) |
| `SMTP_PORT` | SMTP server port (ignored for Resend HTTPS). For other providers: `465` or `587`. | `587` |
| `SMTP_USER` | SMTP authentication username (`resend` for Resend). | None (disabled) |
| `SMTP_PASS` | SMTP password or API key (Resend: `re_…`). | None (disabled) |
| `SMTP_FROM` | Sender address (e.g. `"App Name <noreply@example.com>"`). Domain must be verified with the provider. | None (disabled) |

## Billing

Opt-in account-scoped subscriptions. See [billing](/docs/framework/billing). Sign-in stays free; a plan is an add-on.

| Variable | Description | Default |
|----------|-------------|---------|
| `NEXT_PUBLIC_BILLING_ENABLED` | Set to `"true"` to show `/account/billing` and `/pricing` and to emit entitlement claims. In `next dev`, on unless `"false"`. | `false` (production) |
| `BILLING_PROVIDER` | Default checkout toggle (`stripe` card or `zoneless` USDC). Not exclusive — both processors can be configured. | `stripe` |
| `STRIPE_SECRET_KEY` | Stripe restricted API key (`rk_…` preferred) or secret key. Server-only. | None |
| `STRIPE_WEBHOOK_SECRET` | Signing secret for `{BETTER_AUTH_URL}/api/auth/billing/webhook`. | None |
| `BILLING_STRIPE_PRICE_PREMIUM_MONTHLY` | Stripe Price ID for the Premium monthly plan. | None |
| `BILLING_STRIPE_PRICE_PREMIUM_YEARLY` | Stripe Price ID for the Premium yearly plan. | None |
| `ZONELESS_API_KEY` | Zoneless secret API key for your instance. Server-only. | None |
| `ZONELESS_API_URL` | Origin of your Zoneless API **without** `/v1`. | None |
| `ZONELESS_WEBHOOK_SECRET` | Signing secret for `{BETTER_AUTH_URL}/api/auth/billing/webhook/zoneless`. | None |
| `BILLING_ZONELESS_PRICE_PREMIUM_MONTHLY` | Zoneless Price ID for the Premium monthly plan. | None |
| `BILLING_ZONELESS_PRICE_PREMIUM_YEARLY` | Zoneless Price ID for the Premium yearly plan. | None |
| `BILLING_TRIAL_DAYS` | Optional trial length on a user’s first subscribe. | None |

## Observability

Optional. PostHog, Sentry, and tracing each stay off until their variables are set. Behavior, scrubbing, and backend choice are in [observability](/docs/framework/observability).

### PostHog

| Variable | Description | Default |
|----------|-------------|---------|
| `NEXT_PUBLIC_POSTHOG_KEY` | PostHog project API key. Enables browser and server capture, identify, and feature-flag checks. | None (disabled) |
| `NEXT_PUBLIC_POSTHOG_HOST` | PostHog API host. The browser sends through `/ingest` on this app; the server SDK calls this host directly. | `https://us.i.posthog.com` |
| `NEXT_PUBLIC_POSTHOG_SESSION_REPLAY` | Set to `"true"` to record sessions. Inputs are masked. | Off |

### Sentry

Errors only. Traces stay on the OpenTelemetry pipeline.

| Variable | Description | Default |
|----------|-------------|---------|
| `NEXT_PUBLIC_SENTRY_DSN` | Browser DSN. Also used on the server when `SENTRY_DSN` is unset. | None (disabled) |
| `SENTRY_DSN` | Server and edge DSN. | Falls back to `NEXT_PUBLIC_SENTRY_DSN` |
| `SENTRY_ENVIRONMENT` | Server environment name on events. | `NODE_ENV` |
| `NEXT_PUBLIC_SENTRY_ENVIRONMENT` | Browser environment name. | `NODE_ENV` |
| `SENTRY_RELEASE` | Server release identifier. | None |
| `SENTRY_ORG` | Organization slug. Used only for source map upload. | None |
| `SENTRY_PROJECT` | Project slug. Used only for source map upload. | None |
| `SENTRY_AUTH_TOKEN` | Build-time token. Source maps upload only when this is set. | None |

### OpenTelemetry

`OTEL_BACKEND` selects the trace exporter. Unset or `off` registers no tracer.

| Variable | Description | Default |
|----------|-------------|---------|
| `OTEL_BACKEND` | `otlp`, `gitlab`, or `signoz`. | Off |
| `OTEL_SERVICE_NAME` | `service.name` resource attribute. | `better-auth-server` |
| `OTEL_SERVICE_VERSION` | `service.version` when set. | None |
| `OTEL_TRACES_SAMPLE_RATE` | Root sample ratio from 0 to 1. | `1` in development, `0.1` in production |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | Collector base URL for `otlp` (for example `http://localhost:4318`). | None |
| `OTEL_EXPORTER_OTLP_HEADERS` | Comma-separated `key=value` headers for `otlp`. | None |
| `GITLAB_HOST` | GitLab origin for `gitlab`. | `https://gitlab.com` |
| `GITLAB_PROJECT_ID` | Project id used in the traces URL and `gitlab.project.id`. | None |
| `GITLAB_OBSERVABILITY_TOKEN` | Project access token sent as `PRIVATE-TOKEN`. Server-only. | None |
| `GITLAB_OTEL_ENDPOINT` | Optional full collector URL. Replaces the derived project URL. | None |
| `SIGNOZ_INGEST_URL` | SigNoz Cloud ingest origin or a self-hosted collector (`http://host:4318`). | None |
| `SIGNOZ_INGESTION_KEY` | Cloud ingestion key. Omit for a self-hosted collector. Server-only. | None |

## Prefix conventions

| Prefix | Visibility |
|--------|------------|
| `NEXT_PUBLIC_` | Exposed to the browser. Safe only for non-secret values. |
| *(no prefix)* | Server-only. Never sent to the client. |
